# DART 기업분석 에이전트

반도체 밸류체인(소자·장비·소재) 기업을 DART 전자공시 원본에서 직접 읽어
**경쟁사 비교표**와 **사업보고서 연도별 서술 변화**를 리포트로 뽑는다.

**▶ [리포트 보기](https://kjh1021.github.io/dart-agent/)** — 반도체 소재사 × IDM 5개년 비교

## 왜 이 구조인가

시중의 DART 래퍼는 대부분 "조회"에서 끝난다. 숫자를 받아오는 건 쉽고,
어려운 건 ① 기업마다 다른 계정명을 같은 축으로 세우는 정규화와
② 숫자에 안 잡히는 전략 변화를 본문에서 잡아내는 일이다. 그래서 4계층으로 나눴다.

```
수집        client.py      인증·에러코드·호출간격·캐시
           corpcode.py    기업명/종목코드 → corp_code (10만 건, 7일 캐시)
정규화      financials.py  XBRL account_id 1순위 + 계정명 정규식 2순위 → 표준 20항목
계산        metrics.py     수익성·안정성·활동성·투자강도 비율
           compare.py     다중 기업 매트릭스 / 지표별 추이
서술추적    filings.py     사업보고서 원문 XML → 섹션 분해 → 문장 단위 diff
출력        report.py      단일 HTML 리포트 (라이트/다크 대응)
```

## 설치

```bash
pip install -r requirements.txt
cp .env.example .env      # DART_API_KEY 입력
```

키 발급: <https://opendart.fss.or.kr> 가입 → Open API → 인증키 신청/관리 → 40자리 키 즉시 발급.
비용 없음, 일 20,000회 한도.

## 사용

```bash
# 기업명 확인 (corp_code / 종목코드 출력)
python -m dart_agent.cli search 케미칼

# 소재 그룹 4개년 비교
python -m dart_agent.cli compare --group 소재 --years 2021-2024

# 직접 지정 + 사업보고서 서술 변화까지
python -m dart_agent.cli compare 동진쎄미켐 솔브레인 한솔케미칼 \
    --years 2022-2024 --diff --out out/소재비교.html
```

`config/companies.yaml`에 그룹(소자·장비·cmp·소재·포토·후공정), 볼 섹션, 추이 지표가 정의돼 있다.

## 산출 지표

| 분류 | 지표 |
|---|---|
| 수익성 | 매출총이익률, 영업이익률, 순이익률, ROE, ROA |
| 안정성 | 부채비율, 유동비율, 자기자본비율 |
| 활동성 | 재고자산회전율, **재고회전일수**, 매출채권회전일수, 총자산회전율 |
| 투자강도 | **CAPEX/매출**, 감가상각/매출, 영업CF/매출, 잉여현금흐름 |
| 인력 | 직원수, 1인당매출 |

굵은 항목이 반도체 사이클 판독의 핵심이다. 다운턴에는 재고회전일수가 먼저 늘고
CAPEX/매출이 꺾인 뒤 6~12개월 시차로 장비·소재사 매출에 반영된다.

## 사업보고서 diff

`--diff`는 두 연도의 사업보고서 원문을 받아 「사업의 개요」·「원재료 및 생산설비」·
「주요계약 및 연구개발활동」 등을 문장 단위로 비교한다. 신규 라인 언급, 고객사 구성 변화,
새로 추가된 리스크 문구가 초록(추가)/빨강(삭제)으로 나온다.

## 설계상 알려진 한계

- **주가·시가총액 없음.** DART에는 없는 데이터다. PER/PBR이 필요하면 KRX 소스를 별도로 붙여야 한다.
- **연결/별도 혼용.** 연결 우선, 없으면 별도로 폴백하고 리포트에 표기한다. 비교 시 확인 필요.
- **정정공시.** `last_reprt_at=Y`로 최종본을 받지만, 재무 API는 최초 제출 기준일 수 있다.
- **섹션 제목 흔들림.** 기업·연도별 목차 표기가 달라 일부 섹션은 매칭에 실패할 수 있다.
  `filings.DEFAULT_SECTIONS`와 `HEADING` 정규식을 조정하면 된다.
- 캐시는 `cache/`에 무기한 남는다. 최신 공시를 다시 받으려면 `--no-cache` 또는 해당 파일 삭제.

리포트는 기계적 추출·계산 결과다. 투자 판단 자료가 아니다.
